# 参考资料

这个目录用来放从旧项目中提炼出来、可复用的上下文。

默认按项目建子目录，例如：

- `references/kelingsys/`
- `references/project-a/`
- `references/general/`

适合放在这里的内容有：

- 以前的 PRD 片段
- 发布说明
- 截图
- 复制出来的 API 请求或响应示例
- 对当前需求有帮助的架构说明

默认不要把整份旧仓库复制到这里。真的需要看实现细节时，更合适的做法是把旧项目挂载到 `projects/旧项目名/`，然后只把有价值的结论沉淀在对应的 `references/旧项目名/` 目录里。
